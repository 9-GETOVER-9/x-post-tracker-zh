Chrome 扩展，统计当前浏览器中 X 账号成功发布的帖子和回复，并显示每日、每周数据及活动热力图。

<a id="section-1"></a>

## 安装

1. 打开 `chrome://extensions/`，开启开发者模式。
2. 选择“加载已解压的扩展程序”，选中本仓库目录。
3. 在已登录 X 的浏览器标签页刷新页面，再开始使用。

本扩展从安装后开始记录当前浏览器中观察到的活动；不会自动补录历史数据。数据保存在浏览器扩展的本地存储中。X 页面或接口变化后，统计可能需要适配。

<a id="section-2"></a>

## 检查

仓库中的 JavaScript 可用 `node --check` 进行语法检查。实际发帖和回复的识别仍需在登录后的 X 页面验证。
